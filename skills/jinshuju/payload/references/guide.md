# 金数据 MCP 使用指南

> 一句话介绍：让 AI 助手直接读写你的金数据表单——"搭表单、改字段、查数据、批改数据、看账单"都能用一句中文搞定，不用登录后台。

---

## 一、适用场景

| 角色 | 典型场景 |
| --- | --- |
| 🎯 市场 / 运营 | 活动报名表、问卷；筛选"昨天报名 & 来自上海"的线索 |
| 🛒 销售 / 客服 | 线索登记、批量更新跟进状态、补录数据 |
| 👥 HR / 行政 | 招聘登记、员工信息收集、培训签到 |
| 📊 产品 / 数据 | 调研问卷、多表单汇总分析 |
| 💼 财务 / 老板 | 查账单和付款记录 |

共同特征：**需求已经在文档 / 聊天里写好，不想再切到后台手工操作一遍**。

---

## 二、安装配置

### 前置条件

- 已注册**金数据**账号（[jinshuju.net](https://jinshuju.net)），免费版可体验
- 已安装并登录**SeaHarness 桌面客户端**

### 三步装好

1. **安装连接器**：在客户端的连接器列表里找到「金数据」并安装（连接器 ID `jinshuju-mcp`）
2. **授权**：点「授权」，浏览器会打开金数据登录页——用手机号 / 邮箱 / 扫码登录，点「允许」
3. **回到客户端**：连接器状态变成 ✅ 即完成

不需要申请 API Key/Secret，不需要生成 Base64，也不需要手写 `mcp.json`。凭据由客户端托管，该连接器支持自动刷新。

### 首次验证

在对话框发送：

> 列一下我金数据里最近 5 个表单

若能返回表单列表，说明全流程打通。🎉

## 三、效果展示

### 案例 1｜一句话搭表单

**输入：**

> 帮我建一个"2026 春季发布会报名表"，字段：姓名（必填）、手机号（必填、校验）、公司、职位、参会城市（下拉：北京/上海/深圳/线上）、感兴趣议题（多选）、备注。主题用蓝色简洁风格。

**对比：**

| | 手工搭建 | MCP 一句话 |
| --- | --- | --- |
| 步骤 | 登录 → 新建 → 拖字段 → 设置校验 → 调主题 | 发一句话 |
| 耗时 | 10–15 分钟 | 10 秒 |
| 出错面 | 字段漏设必填 / 校验 | 一次生成完整 |

### 案例 2｜条件查询

**输入：**

> 查"春季发布会报名表"里参会城市=上海 且 跟进状态=未跟进 的记录，按时间倒序给前 20 条，只要姓名、手机号、公司。

**输出（脱敏展示）：**

| 姓名 | 手机号 | 公司 | 报名时间 |
| --- | --- | --- | --- |
| 张\* | 138\*\*\*\*1234 | A 科技 | 2026-04-16 18:22 |
| 李\* | 139\*\*\*\*5678 | B 咨询 | 2026-04-16 15:07 |
| …（共 20 条） | | | |

**价值**：结果直接可被 AI 接续——写跟进话术、生成 CSV、发企微——不用跳出对话流。

### 案例 3｜批量改状态

**输入：**

> 把"报名表"里手机号以 138 开头的记录，跟进状态都改成"已联系"。

**效果**：先列命中记录让你确认 → 确认后再批量更新 → 汇总成功 / 失败条数。

### 案例 4｜账单查询

**输入：**

> 列一下我金数据账号最近 3 个月的付款记录。

**输出**：直接返回订单号、金额、套餐、付款时间。不用进「账户中心 → 账单明细」。

## 四、常见误区 & Tips

### ⚠️ 常见误区

1. **"要把数据传给 AI"才能分析** —— 不需要。AI 通过 MCP 拉数据，**数据不离开金数据**。
2. **"改错了没法恢复"** —— 批量操作前 AI 会让你确认；单条修改有历史记录可查。
3. **"用户说中文字段名 AI 就能直接写进去"** —— 不行。金数据 API 的 entry payload 键是每个字段的 `api_code`（如 `field_1`、`field_mobile`），不是中文 label。AI 每次都会先 `get_form` 拿映射再写，这是正常流程，不用人工转换——你说中文就行。
4. **"连接显示 ✅ 但工具不响应"** —— 多半是授权被撤销或过期，到连接器列表重新授权「金数据」即可。
5. **"一次只能做一件事"** —— 一条 prompt 可串多个工具（复制表单 → 改标题 → 换主题 → 统计数据）。
6. **"数据量大也能一次拉回来"** —— `list_entries` 单次上限 50 条，分页靠游标。几千条记录会分页拉取，耗时随数据量增长。

### 💡 使用 Tips

- **✨ 先「看一眼」再动手**：批量操作前让 AI 先 `get_form` 确认字段，准确率更高
- **✨ 带时间 + 数量**：避免一次拉几千条，加"最近 7 天""前 50 条"更稳
- **✨ 主动要求脱敏**：「手机号打星」「只显示姓氏」AI 会自动处理
- **✨ 两步法做报表**：第一步 MCP 拉数据，第二步让 AI 用代码做透视图
- **✨ 把常用操作固化成 prompt 模板**：例如「每周一自动拉上周新增数据摘要」

### 🆘 遇到问题

| 现象 | 解决办法 |
| --- | --- |
| 一直转圈连不上 | 刷新重试；仍失败 → 在连接器列表里重新授权，或卸载后重装连接器 |
| 字段类型建不出来 | 部分高级字段（电子签名、富文本）需付费套餐 |
| 提示"表单不存在" | 核对 form_token；确认是同一个金数据账号 |
| 操作被拒绝 | 该表单是协作表单且你无编辑权限，联系所有者 |

## 五、安全与权限

- 所有操作都按连接器绑定的金数据账号权限执行——看不到你无权访问的数据
- 重要操作（批量删除、覆盖字段）AI 会要求显式确认
- 凭据由客户端连接器托管，不在技能目录、不在 `mcp.json`、也不进对话上下文；可随时在金数据「设置 → 授权管理」中撤销对应客户端的授权
