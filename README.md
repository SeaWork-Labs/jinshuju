# jinshuju

金数据表单平台操作：用自然语言搭建表单、查询与批量修改数据、核对账单。

## 安装

从 GitHub 装（需要本机有 `git`）：

```bash
npx skills add SeaWork-Labs/jinshuju#v1.0.4 --skill jinshuju
```

从市场索引装（纯 HTTPS，国内网络可达）：

```bash
npx skills add https://skills.seaharness.cn --skill jinshuju
```

## 内容

技能正文在 `skills/jinshuju/payload/`。这些文件由转换器从市场归档逐字节搬来，改动请直接改 `skills/jinshuju/payload/`，不要反向同步。版本以 git tag 为准。
